# LMS Frontend Client

This directory contains the React frontend for the Learning Management System (LMS).

## Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Run Development Server

```bash
npm run dev
```

The application runs on `http://localhost:5173`. Make sure the backend API is running on `http://localhost:5000`.

### 3. Build for Production

```bash
npm run build
```

### 4. Preview Production Build

```bash
npm run preview
```

## Key Technologies

- React 19
- Vite 8
- TypeScript 7
- React Router 7
- TanStack Query
- React Hook Form
- Zod
- Vanilla CSS Design System
